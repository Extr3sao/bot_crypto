# OPP-0009 — Intraday/overnight seasonality in Bitcoin (hour-of-day windows)

- rank: **REJECT** · evidence score: **17/50** · status: `REJECTED_MULTIPLE_TESTING_AND_COST`
- sources: S-18
- market: BTC spot
- assets: BTC
- timeframe: hourly, day-of-week x hour-of-day

## Economic hypothesis

Crypto trading activity is concentrated in particular clock windows (US cash hours, Asian open, overnight). If some windows persistently carry positive drift, a strategy that holds BTC only in those windows should earn it.

## Rules as stated by the source (nothing invented)

- entry: PARTIAL: hold BTC during a named hour window (the source highlights 22:00 and 23:00 UTC, and calls 04:00 the worst). The window itself is a mined parameter.
- exit: PARTIAL: exit at the end of the window (implied by the construction).
- risk: UNKNOWN as a source rule; a window strategy earns nothing when the drift is absent and still pays two round trips per day.
- parameters: A single hour selection plus day-of-week conditioning.

## Claimed evidence

- period: UNKNOWN
- metrics: companion backtest reports about 0.07% average return for the best hour; the source ranks 22:00/23:00 as best and 04:00 as worst
- transaction cost model: NONE (the blog reproduction does not state fee assumptions)
- external code: NONE
- external results: Strategy-blog reproduction of an academic observation; no peer-reviewed tradability result in the registry for this line.
- forward evidence: NONE · live evidence: NONE

## Required data

hourly BTC OHLCV (public)

## Counter-evidence

- About 7 bps gross for the best hour cannot pay a 23.791 bps round trip; entering and exiting daily is a guaranteed cost with the same magnitude as the effect.
- Twenty-four hours x seven days is 168 candidate windows: selecting the best one is textbook multiple testing, and the source shows the ranking, not its stability.
- Seasonality of this kind is exactly the 'different threshold' pattern the reentry policy rejects.
- The project already has a strong internal result in the neighbouring space: intraday/daily price-directional effects are weak and cost-sensitive (WHERE_WE_ARE.md).

## Ambiguities

- Whether the selected hour is stable out of sample is not shown.
- No cost model, no turnover accounting.
