# OPP-0015 — pysystemtrade / Carver's diversified trend-following system

- rank: **REJECT** (RFC-035S2 round-2 candidate)
- sources: S2-14, S2-13
- rule completeness: 16/21
- evidence: E3 — a long-lived open-source implementation of a published system with decades of public discussion
- entry: in the engine: EWMAC/breakout/carry forecast combination above the configured threshold
- exit: via position sizing and forecast scaling rather than a price stop; no target is used; not applicable; forecast decay/sign change
- parameters: in the engine's configuration files and the book
- costs: the engine carries explicit cost assumptions
- unknowns: market, assets, exit_target, exit_time, original_metrics

## Gaps to P0

- the instrument class is wrong for this runtime (futures, leverage, shorting)
- a spot-crypto long/cash version would be our own design, not this external strategy

## Counter-evidence

- reproducing it exactly requires a futures account, margin and 100 markets — none of which this project can trade
- keeping only the trend component on BTC spot would be a new strategy, and the mission forbids relabelling our own design as an external replication
- the project's admission cost is a 23.791 bps round trip, and the source declares no cost model (the engine carries explicit cost assumptions)
- found in the RFC-035S2 strategy-first search; no local backtest influenced this record
