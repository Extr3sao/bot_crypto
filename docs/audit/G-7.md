## 1. Resultado en una frase

El recorrido real **sí se ejecutó**:

```text
Binance public REST → validación PIT → contexto → StrategyRegistry/Router
→ NO_TRADE explícito → Risk/Execution no invocados → estado durable
```

pero **no existe ninguna estrategia admitida para PAPER** en el ledger
comprometido (24 estrategias, 0 con `admitted_for_paper=true`). Por tanto G-7
**no puede cerrarse como PASS**: la condición 3 de aceptación exige una
estrategia elegible real, y fabricar una admisión o forzar una señal sería
exactamente el `FALSE_SUCCESS` que el contrato prohíbe.

## 3. Runtime autoritativo

No se creó un segundo runtime. El entrypoint sigue siendo:

```text
scripts/start_paper_trading.py::build_cycle_engine
  → PaperOrchestrator → PaperSessionRunner → PaperCycleEngine
      → CryptoAssetAgentRegistry (contexto PIT)
      → StrategyRouter (única autoridad de selección)
      → familias existentes (ema_crossover, momentum, breakout, trend,
        mean_reversion, volatility)
      → RiskManager
      → HotStopGate.order_boundary
      → DurablePaperBroker → PaperStateStore → StartupReconcilerV4
```

`PaperCycleEngine` no importa `autonomous.decision`; esa duplicidad sigue
abierta y no se declara resuelta. El detalle está en
`docs/audit/runtime_authority_map.md` §14.

## 5. Por qué no hubo PAPER_TRADE

`config/strategy_admission.json` es la única autoridad. Contiene 24 entradas y
**ninguna** tiene `admitted_for_paper=true`:

- `COST_KILLED = 7`
- `NO_GROSS_EDGE = 17`
- `PAPER_CANDIDATE = 0`
- `PAPER_ACTIVE = 0`

Las 72 evaluaciones de la campaña (4 informes × 3 activos × 6 estrategias 5m)
terminaron en `NOT_APPLICABLE`, con razones del tipo
`status=NO_GROSS_EDGE, need one of ['PAPER_ACTIVE', 'PAPER_CANDIDATE']`.
No se modificó el ledger, no se inventó una señal y no se promocionó ninguna
familia. El detalle está en `STRATEGY_ELIGIBILITY_REPORT.md`.

## 10. Límites

- `PAPER_ONLY`: no se construyó ningún cliente de exchange, no se leyeron
  credenciales y no se envió ninguna orden real.
- La verificación es `PROCEDURALLY_SEPARATED` (script distinto, mismo autor),
  no una segunda persona.
- El forward es una observación puntual, no una sesión de 24 h.
- La captura cubre 41 h 40 m de velas 5m; no se declara cobertura de otros
  regímenes.
- `LIVE_NO_GO` y `PRODUCTION_READY = false` se mantienen.
